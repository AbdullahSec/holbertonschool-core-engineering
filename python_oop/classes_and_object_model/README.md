# Python - Object-Oriented Programming (OOP): Classes and Object Model

## Description
This project introduces the fundamentals of Object-Oriented Programming (OOP) in Python. It covers the core mechanics of creating classes, instantiating objects, managing instance attributes, enforcing data encapsulation using private attributes, implementing properties (getters and setters), defining methods, and overriding special string representation methods.

## Requirements
- Allowed editors: `vi`, `vim`, `emacs`
- Operating System: Ubuntu 20.04 LTS
- Python version: Python 3.8.x
- Style guidelines: `pycodestyle` (version 2.7.*)
- All files must be executable and end with a new line
- All modules, classes, and methods must have full documentation (Docstrings)

## Tasks Overview

| File | Description |

| `1-square.py` | `Square` class with a private instance attribute `size`. |
