# Python File Handling

This project contains Python functions for reading from and writing to UTF-8 text files.

## Tasks

### 0. Read file
Read a UTF-8 text file and print its contents to standard output.

### 1. Write to a file
Write a string to a UTF-8 text file and return the number of characters written. The file is created if it does not exist and overwritten if it already exists.

### 2. Append to a file
Append a string to the end of a UTF-8 text file and return the number of characters added. The file is created if it does not exist.

## Requirements

- Python 3
- Use the `with` statement when working with files.
- No external modules or imports.
- File permission and missing file exceptions do not need to be handled.

## Files

- `append_write.py`
